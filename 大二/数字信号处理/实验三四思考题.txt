实验三：IIR数字滤波器的设计 代码实现

% =========================================================================
% 实验三：IIR数字滤波器的设计
% =========================================================================
clc; clear; close all;

%% 1. 生成混合信号 (模拟mstg函数的功能)
Fs = 10000;         % 采样频率
T = 1/Fs; Tp = 0.08;% 采样周期和观察时间
N = Tp*Fs;          % 信号长度 N=800
t = 0:T:(N-1)*T;    % 时间向量
k = 0:N-1; f = k*Fs/N; % 频率向量

% 信号生成参数
fc1 = Fs/10; fm1 = fc1/10; % 第1路：载波1000Hz，调制100Hz (频点: 900, 1100Hz)
fc2 = Fs/20; fm2 = fc2/10; % 第2路：载波500Hz，调制50Hz  (频点: 450, 550Hz)
fc3 = Fs/40; fm3 = fc3/10; % 第3路：载波250Hz，调制25Hz  (频点: 225, 275Hz)

xt1 = cos(2*pi*fm1*t).*cos(2*pi*fc1*t);
xt2 = cos(2*pi*fm2*t).*cos(2*pi*fc2*t);
xt3 = cos(2*pi*fm3*t).*cos(2*pi*fc3*t);
st = xt1 + xt2 + xt3; % 混合信号
fxt = fft(st, N);     % 计算频谱

% 绘制混合信号的时域波形和频谱
figure('Name', '实验三：混合信号的时域和频域');
subplot(2,1,1); plot(t, st); grid on;
xlabel('t/s'); ylabel('s(t)'); title('(a) s(t)的波形');
axis([0 0.08 min(st) max(st)]);
subplot(2,1,2); stem(f(1:N/2), abs(fxt(1:N/2))/max(abs(fxt)), '.'); grid on;
xlabel('f/Hz'); ylabel('幅度'); title('(b) s(t)的频谱');
axis([0 2000 0 1.2]);

%% 2. 设计IIR椭圆滤波器并分离信号
Rp = 0.1; Rs = 60; % 通带最大衰减0.1dB，阻带最小衰减60dB

% (1) 低通滤波器提取 xt3 (中心频率250Hz左右)
wp1 = 300/(Fs/2); ws1 = 400/(Fs/2); % 设定通带300Hz，阻带400Hz
[N1, Wn1] = ellipord(wp1, ws1, Rp, Rs);
[b1, a1] = ellip(N1, Rp, Rs, Wn1);
y1 = filter(b1, a1, st);

% (2) 带通滤波器提取 xt2 (中心频率500Hz左右)
wp2 = [400 600]/(Fs/2); ws2 = [300 700]/(Fs/2); % 设定通带400-600Hz
[N2, Wn2] = ellipord(wp2, ws2, Rp, Rs);
[b2, a2] = ellip(N2, Rp, Rs, Wn2);
y2 = filter(b2, a2, st);

% (3) 高通滤波器提取 xt1 (中心频率1000Hz左右)
wp3 = 800/(Fs/2); ws3 = 700/(Fs/2); % 设定通带>800Hz，阻带<700Hz
[N3, Wn3] = ellipord(wp3, ws3, Rp, Rs);
[b3, a3] = ellip(N3, Rp, Rs, Wn3);
y3 = filter(b3, a3, st);

%% 3. 绘制滤波器损耗函数与分离出的信号
figure('Name', '实验三：滤波器响应与滤波结果', 'Position', [100, 100, 800, 800]);

% 低通滤波结果
[H1, w1] = freqz(b1, a1, 512);
subplot(3,2,1); plot(w1/pi, 20*log10(abs(H1))); grid on;
title('低通滤波器损耗曲线'); xlabel('\omega/\pi'); ylabel('幅度(dB)'); axis([0 1 -80 10]);
subplot(3,2,2); plot(t, y1); grid on;
title('提取的低通信号 (250Hz)'); xlabel('t/s'); ylabel('y_1(t)'); axis([0 0.08 -1 1]);

% 带通滤波结果
[H2, w2] = freqz(b2, a2, 512);
subplot(3,2,3); plot(w2/pi, 20*log10(abs(H2))); grid on;
title('带通滤波器损耗曲线'); xlabel('\omega/\pi'); ylabel('幅度(dB)'); axis([0 1 -80 10]);
subplot(3,2,4); plot(t, y2); grid on;
title('提取的带通信号 (500Hz)'); xlabel('t/s'); ylabel('y_2(t)'); axis([0 0.08 -1 1]);

% 高通滤波结果
[H3, w3] = freqz(b3, a3, 512);
subplot(3,2,5); plot(w3/pi, 20*log10(abs(H3))); grid on;
title('高通滤波器损耗曲线'); xlabel('\omega/\pi'); ylabel('幅度(dB)'); axis([0 1 -80 10]);
subplot(3,2,6); plot(t, y3); grid on;
title('提取的高通信号 (1000Hz)'); xlabel('t/s'); ylabel('y_3(t)'); axis([0 0.08 -1 1]);

实验四：FIR数字滤波器的设计 代码实现

% =========================================================================
% 实验四：FIR数字滤波器的设计
% =========================================================================
clc; clear; close all;

%% 1. 生成含噪信号 (模拟xtg函数)
N = 1000; Fs = 1000;
T = 1/Fs; Tp = N*T;
t = 0:T:(N-1)*T;
k = 0:N-1; f = k/Tp;

% 生成信号 st (100Hz载波，10Hz调制 -> 包含90Hz和110Hz分量)
fc = Fs/10; f0 = fc/10;
mt = cos(2*pi*f0*t);
ct = cos(2*pi*fc*t);
st = mt .* ct;

% 产生高频噪声 (使用firpmord和firpm替代旧版remezord和remez)
nt = 2*rand(1, N) - 1; % 随机噪声
fp_n = 150; fs_n = 200; Rp_n = 0.1; As_n = 70;
dev_n = [10^(-As_n/20), (10^(Rp_n/20)-1)/(10^(Rp_n/20)+1)];
[n_ord, fo, mo, w_weight] = firpmord([fp_n, fs_n], [0, 1], dev_n, Fs); % 设计高通滤波器生成噪声
hn_noise = firpm(n_ord, fo, mo, w_weight);
nht = filter(hn_noise, 1, 10*nt); % 生成含有高频成分的噪声

xt = st + nht; % 含噪混合信号
fxt = fft(xt, N);

figure('Name', '实验四：含噪声信号');
subplot(2,1,1); plot(t, xt); grid on;
xlabel('t/s'); ylabel('x(t)'); title('(a) 信号加噪声波形'); axis([0 0.5 min(xt) max(xt)]);
subplot(2,1,2); plot(f(1:N/2), abs(fxt(1:N/2))/max(abs(fxt))); grid on;
xlabel('f/Hz'); ylabel('幅度'); title('(b) 信号加噪声的频谱'); axis([0 500 0 1.2]);

%% 2. 窗函数法设计FIR低通滤波器
% 信号频率最高110Hz，噪声最低150Hz。设定通带截止120Hz，阻带截止150Hz。
fp = 120; fs_stop = 150; 
As = 60; % 要求阻带衰减60dB，需选择黑斯曼窗(Blackman)或凯撒窗。此处选用Blackman窗。
delta_f = fs_stop - fp;
Wn = (fp + fs_stop) / 2 / (Fs/2); % 归一化截止频率

% 计算Blackman窗所需的阶数，N ≈ 5.5 * Fs / delta_f
M = ceil(5.5 * Fs / delta_f); % 滤波器阶数M
if mod(M,2)==1 % 确保为偶数阶(Type I)，避免在Nyquist处增益为0的限制(虽然低通影响不大)
    M = M + 1;
end
win = blackman(M+1);
hn = fir1(M, Wn, 'low', win);

%% 3. 使用fftfilt进行滤波
yt = fftfilt(hn, xt);

%% 4. 绘图
figure('Name', '实验四：滤波器特性与输出');
[H, w] = freqz(hn, 1, 512);
subplot(2,1,1); plot(w/pi * (Fs/2), 20*log10(abs(H))); grid on; % X轴转换为Hz方便观察
title('(a) 窗函数法设计的低通滤波器幅频特性'); xlabel('f/Hz'); ylabel('幅度(dB)'); axis([0 500 -120 10]);
subplot(2,1,2); plot(t, yt); grid on;
title('(b) 窗函数法设计的滤波器滤除噪声后的信号波形'); xlabel('t/s'); ylabel('y_t(t)'); axis([0 0.5 -1 1]);

第二部分：分析比较实验结果，简述得出的结论

1. 实验三（IIR滤波器）结果分析：

  - 分析： 原始混合信号在时域上混叠在一起无法分辨，但在频域上清晰地显示出分布在 250Hz (225,275)、500Hz (450,550)
    和 1000Hz (900,1100) 附近的三个独立频带。通过设计通带和阻带精准的椭圆低通、带通、高通滤波器，利用滤波器的频率选择性。
  - 结论：
    IIR椭圆滤波器在阶数较低的情况下，就能获得非常陡峭的过渡带（从损耗函数曲线可以看出）。滤波后的输出信号时域波形恢复了经典的双边带调幅(DSB-SC)波形特征的包络，成功实现了多路频分复用信号的无失真分离。

2. 实验四（FIR滤波器）结果分析：

  - 分析：
    原始信号受到强烈的高频噪声干扰，时域波形完全被噪声淹没。频谱图显示，有效信号集中在90Hz和110Hz，而噪声成分集中在150Hz以上。采用Blackman窗设计的FIR低通滤波器，其过渡带足够窄，且阻带衰减大于60dB。使用
    fftfilt 快速卷积滤波后，成功滤除了150Hz以上的高频噪声。
  - 结论：
    窗函数法能有效设计出满足各项指标的FIR滤波器。相较于IIR滤波器，FIR滤波器实现了严格的线性相位，保证了提取出的信号包络和载波在时间上没有发生相移畸变（这对于通信信号解调至关重要），有效实现了强噪声背景下的信号提取。

第三部分：简要回答思考题

实验三 思考题解答：

（1）阅读信号产生函数mstg，确定三路调幅信号的载波频率和调制信号频率。 根据代码 fc = Fs/10, fm = fc/10 以及对应的分频系数，可得：

  - 第1路： 载波频率 f_{c1} = 10000/10 = 1000 Hz，调制频率 f_{m1} = 1000/10 = 100 Hz。
  - 第2路： 载波频率 f_{c2} = 10000/20 = 500 Hz，调制频率 f_{m2} = 500/10 = 50 Hz。
  - 第3路： 载波频率 f_{c3} = 10000/40 = 250 Hz，调制频率 f_{m3} = 250/10 = 25 Hz。

（2）信号产生函数mstg中采样点数N=1600，对其进行N点FFT可以得到6根理想的谱线。如果取N=1800，结果如何？为什么？N=2000又如何？

  - N=1800时： 会出现**频谱泄露（Spectral Leakage）**现象，原本锐利的6根谱线会变宽，底部出现“裙边”。
      - 原因： FFT的频率分辨率为 \Delta f = F_s/N = 10000/1800 \approx 5.55
        Hz。信号的各频点（如225Hz, 275Hz等）不是 \Delta f
        的整数倍，即截断窗口内不包含完整的整数个信号周期，导致做FFT时能量向相邻频率泄漏。
  - N=2000时： 依然可以得到锐利清晰的6根理想谱线。
      - 原因： \Delta f = 10000/2000 = 5
        Hz。由于所有的信号频点（225, 275, 450, 550, 900, 1100）末尾均是0或5，它们全都是5Hz的整数倍。因此截断时正好包含了各信号成分的整数个周期，满足整周期截断条件，不会发生频谱泄露。

实验四 思考题解答：

1. 如果给定通带截止频率、阻带截止频率以及阻带最小衰减，如何用窗函数法设计线性相位低通滤波器？请写出设计步骤。 步骤如下：

1.  确定窗函数类型： 根据阻带最小衰减 A_s 选择满足条件的窗函数（例如 A_s=60dB 需选择 Blackman 窗，其最大阻带衰减可达 74dB）。
2.  计算滤波器阶数(或长度)： 根据过渡带宽度 \Delta f = f_s - f_p 和所选窗函数的特性，计算所需滤波器阶数 N（如 Blackman
    窗 N \approx 5.5 F_s / \Delta f）。
3.  计算理想截止频率： 取通带和阻带截止频率的中间值作为理想低通滤波器的截止频率 \omega_c = (\omega_p + \omega_s)/2。
4.  求理想冲激响应： 根据理想低通特性求出其无限长时域冲激响应 h_d(n)。
5.  加窗截断： 将理想冲激响应与所选取的窗函数时域相乘 h(n) = h_d(n) \cdot w(n)，得到最终的 FIR
    滤波器系数（在MATLAB中可直接使用 fir1 函数完成步骤3、4、5）。

2. 指标不变，改用等波纹最佳逼近法设计FIR数字滤波器，调用remezord和remez。解释为何其所需滤波器阶数更低？

  - 原因解释：
    窗函数法设计的滤波器，其通带和阻带的误差（波纹）是不均匀的，越靠近截止频率（过渡带两侧）误差越大，为了满足最坏情况（边缘处）的衰减要求，不得不全局提高滤波器的阶数。
    而等波纹最佳逼近法（Remez算法）采用的是最小最大化（Minimax）准则，它使得误差在整个通带和整个阻带内被均匀散布开来（形成等幅波纹）。因为充分利用了每个频带上的误差余量，没有任何“性能浪费”，所以在满足同样容差指标的情况下，等波纹法能逼近得最好，所需使用的滤波器系数最少，即阶数更低。
