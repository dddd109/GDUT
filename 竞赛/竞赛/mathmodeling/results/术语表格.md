# 术语表 (Terminology)

## 一、核心概念术语

| 中文名称 | 英文名称 | 缩写/符号 | 定义/说明 |
|---------|---------|----------|----------|
| 烟幕干扰弹 | Smoke Jamming Round | - | 无人机投放的烟幕弹，起爆后形成雷达遮蔽云团 |
| 烟幕云团 | Smoke Cloud | - | 干扰弹起爆后形成的球状烟幕区域 |
| 假目标 | Decoy Target | $O$ | 位于原点(0,0,0)，导弹瞄准的虚假目标 |
| 真目标 | Real Target | - | 半径7m、高10m的圆柱体，底面圆心(0,200,0) |
| 无人机 | Unmanned Aerial Vehicle | UAV / FY | 携带干扰弹的飞行平台 |
| 来袭导弹 | Incoming Missile | M | 以300m/s飞向假目标的敌方导弹 |
| 有效遮蔽 | Effective Jamming | - | 导弹-目标连线穿过烟幕云团的状态 |
| 有效遮蔽时长 | Effective Jamming Duration | $J$ | 导弹被有效遮蔽的累计时间 |
| 投放点 | Deployment Point | $\mathbf{P}_d$ | 干扰弹从无人机释放的位置 |
| 起爆点 | Detonation Point | $\mathbf{P}_b$ | 干扰弹爆炸形成烟幕云团的位置 |
| 雷达黑障 | Radar Blackout | - | 烟幕云团对雷达波的遮蔽效应 |

## 二、数学符号术语

| 符号 | 含义 | 单位 |
|-----|------|------|
| $\mathbf{M}_i(t)$ | 导弹 $i$ 在时刻 $t$ 的位置矢量 | m |
| $\mathbf{F}_j(t)$ | 无人机 $j$ 在时刻 $t$ 的位置矢量 | m |
| $\mathbf{C}(t)$ | 烟幕云团中心在时刻 $t$ 的位置矢量 | m |
| $\mathbf{P}_b$ | 干扰弹起爆点位置矢量 | m |
| $\mathbf{P}_d$ | 干扰弹投放点位置矢量 | m |
| $v_m$ | 导弹飞行速度 | m/s |
| $v_j$ | 无人机 $j$ 的飞行速度 | m/s |
| $v_s$ | 烟幕云团下沉速度 | m/s |
| $\theta_j$ | 无人机 $j$ 的飞行方向角（从x轴正向逆时针） | ° |
| $R$ | 烟幕云团有效半径 | m |
| $T_{\text{eff}}$ | 烟幕云团有效持续时间 | s |
| $t_d^k$ | 第 $k$ 枚干扰弹的投放时刻 | s |
| $t_b^k$ | 第 $k$ 枚干扰弹的起爆时刻 | s |
| $g$ | 重力加速度 | m/s² |
| $\mathbf{d}_i$ | 导弹 $i$ 飞行方向的单位向量 | - |
| $\mathbf{g}$ | 重力加速度矢量 | m/s² |

## 三、模型相关术语

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| 运动学模型 | Kinematic Model | 描述各实体运动规律的数学模型 |
| 线段-球相交判定 | Line-Sphere Intersection | 判断导弹视线是否穿过烟幕云团 |
| 粒子群优化 | Particle Swarm Optimization | 用于多维优化问题的启发式算法 |
| 目标分配 | Target Assignment | 将无人机分配给不同导弹的策略 |
| 协同遮蔽 | Cooperative Jamming | 多架无人机联合实施遮蔽干扰 |

## 四、坐标系术语

| 术语 | 说明 |
|------|------|
| 坐标原点 | 假目标位置 (0, 0, 0) |
| x轴正向 | 指向东 (East) |
| y轴正向 | 指向南 (South) |
| z轴正向 | 垂直向上 (Up) |
