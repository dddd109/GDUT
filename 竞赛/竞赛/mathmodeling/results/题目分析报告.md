# 数学建模分析文档 —— 烟幕干扰弹的投放策略

## 一、问题分析

### 1.1 问题背景

在现代战场环境中，无人机投放烟幕干扰弹是重要的隐身突防手段。烟幕干扰弹释放的悬浮微粒能有效散射和吸收雷达电磁波，形成覆盖区域的"雷达黑障"，使来袭导弹无法发现真实目标。本题研究无人机在三维空间中投放烟幕干扰弹以干扰来袭导弹的策略优化问题。

### 1.2 问题重述

在给定的三维空间中：
- 假目标位于原点 $O(0, 0, 0)$，导弹瞄准该假目标飞行
- 真目标为底面圆心 $(0, 200, 0)$、半径 $7\text{m}$、高 $10\text{m}$ 的圆柱体
- 三枚来袭导弹 M1, M2, M3 以 $300\text{m/s}$ 的速度直线飞向假目标
- 五架无人机 FY1~FY5 携带烟幕干扰弹，可在飞行过程中投放
- 烟幕干扰弹起爆后形成半径 $10\text{m}$ 的球形烟幕云团，以 $3\text{m/s}$ 匀速下沉，$20\text{s}$ 内有效
- 无人机飞行速度 $70\sim140\text{m/s}$，在固定高度上匀速直线飞行
- 每架无人机至多携带 3 枚干扰弹，两枚投放间隔不小于 1 秒

需要解决五个逐步递进的问题：
1. 固定参数下计算单机单弹的有效遮蔽时长
2. 优化单机单弹的投放策略使遮蔽时长最大化
3. 单机三弹的最优投放策略
4. 三机协同干扰单枚导弹
5. 五机协同干扰三枚导弹

### 1.3 问题类型

| 问题 | 类型 | 特征 |
|------|------|------|
| 问题1 | 运动学计算 | 固定参数，解析求解 |
| 问题2 | 单变量优化 | 连续优化，2维搜索空间 |
| 问题3 | 多维优化 | 多弹时序优化 |
| 问题4 | 协同优化 | 多智能体任务分配 |
| 问题5 | 多目标协同优化 | 目标分配+多智能体协同 |

## 二、模型建立

### 2.1 坐标系统与基本参数

采用右手直角坐标系：$x$ 轴指向东，$y$ 轴指向南，$z$ 轴垂直向上。

**导弹初始位置与目标**：

| 导弹 | 初始位置 (m) | 目标 | 速度 (m/s) |
|------|-------------|------|-----------|
| M1 | $(20000, 0, 2000)$ | 假目标 $(0,0,0)$ | 300 |
| M2 | $(19000, 600, 2100)$ | 假目标 $(0,0,0)$ | 300 |
| M3 | $(18000, -600, 1900)$ | 假目标 $(0,0,0)$ | 300 |

**无人机初始位置**：

| 无人机 | 初始位置 (m) | 飞行高度 (m) | 速度范围 (m/s) |
|--------|-------------|-------------|---------------|
| FY1 | $(17800, 0, 1800)$ | 1800 | 70~140 |
| FY2 | $(12000, 1400, 1400)$ | 1400 | 70~140 |
| FY3 | $(6000, -3000, 700)$ | 700 | 70~140 |
| FY4 | $(11000, 2000, 1800)$ | 1800 | 70~140 |
| FY5 | $(13000, -2000, 1300)$ | 1300 | 70~140 |

### 2.2 导弹运动模型

导弹 $i$ 以恒定速度 $v_m = 300 \text{m/s}$ 直线飞向假目标原点。其位置随时间 $t$ 的变化为：

$$\mathbf{M}_i(t) = \mathbf{M}_i^0 + v_m \cdot t \cdot \mathbf{d}_i$$

其中方向单位向量 $\mathbf{d}_i = -\frac{\mathbf{M}_i^0}{|\mathbf{M}_i^0|}$，即导弹始终朝向原点飞行。

导弹到达原点的时间 $T_i^{\text{arrive}} = \frac{|\mathbf{M}_i^0|}{v_m}$。

### 2.3 无人机运动模型

无人机 $j$ 在固定高度 $z_j^0$ 上作匀速直线运动，速度 $v_j \in [70, 140]$ m/s，运动方向角 $\theta_j \in [0°, 360°)$（从 $x$ 轴正向逆时针度量）。

$$\mathbf{F}_j(t) = \mathbf{F}_j^0 + v_j \cdot t \cdot (\cos\theta_j, \sin\theta_j, 0)^\top$$

其中 $\mathbf{F}_j^0 = (x_j^0, y_j^0, z_j^0)$ 为初始位置。

### 2.4 烟幕干扰弹运动模型

干扰弹在时刻 $t_d$ 从无人机位置 $\mathbf{F}_j(t_d)$ 投放，具有与投放时刻无人机相同的初始速度，随后在重力作用下运动。设起爆时刻为 $t_b$（$t_b > t_d$），则起爆位置为：

$$\mathbf{P}_b = \mathbf{F}_j(t_d) + \mathbf{v}_j \cdot (t_b - t_d) + \frac{1}{2}\mathbf{g} \cdot (t_b - t_d)^2$$

其中 $\mathbf{v}_j = v_j \cdot (\cos\theta_j, \sin\theta_j, 0)^\top$ 为投放时刻无人机的速度矢量，$\mathbf{g} = (0, 0, -g)^\top = (0, 0, -9.8)^\top \text{m/s}^2$。

### 2.5 烟幕云团运动模型

干扰弹在 $\mathbf{P}_b$ 处起爆后，形成半径 $R = 10\text{m}$ 的球形烟幕云团。云团以速度 $v_s = 3\text{m/s}$ 匀速下沉，有效持续时间 $T_{\text{eff}} = 20\text{s}$。

对于 $t \in [t_b, t_b + T_{\text{eff}}]$，云团中心位置为：

$$\mathbf{C}(t) = \mathbf{P}_b + (0, 0, -v_s \cdot (t - t_b))^\top$$
$$= (x_b, y_b, z_b - 3(t - t_b))^\top$$

### 2.6 有效遮蔽判定模型

**核心判定准则**：导弹到目标的连线穿过烟幕云团时，导弹被有效干扰。

对时刻 $t \in [t_b, t_b + T_{\text{eff}}]$：
1. 计算导弹位置 $\mathbf{M}(t)$
2. 计算烟幕云团中心 $\mathbf{C}(t)$ 和半径 $R = 10\text{m}$
3. 判断线段 $\overline{\mathbf{M}(t)\mathbf{O}}$（导弹到原点）是否与球 $S(\mathbf{C}(t), R)$ 相交

**线段-球相交判定**：
- 定义线段方向 $\mathbf{d} = \frac{\mathbf{O} - \mathbf{M}(t)}{|\mathbf{O} - \mathbf{M}(t)|}$
- 向量 $\mathbf{v} = \mathbf{C}(t) - \mathbf{M}(t)$
- 投影参数 $s = \mathbf{v} \cdot \mathbf{d}$
- 最近点 $\mathbf{P}_{\text{close}} = \mathbf{M}(t) + s \cdot \mathbf{d}$
- 若 $s \in [0, |\mathbf{O} - \mathbf{M}(t)|]$ 且 $|\mathbf{P}_{\text{close}} - \mathbf{C}(t)| \leq R$，则有效遮蔽

**有效遮蔽时长**：所有满足遮蔽条件的 $t$ 的测度之和。

## 三、算法设计

### 3.1 问题1 —— 固定参数计算

**已知参数**：FY1 速度 $v = 120\text{m/s}$，朝向假目标（$\theta = 180°$，即向 $x$ 轴负方向），投放时刻 $t_d = 1.5\text{s}$，起爆时刻 $t_b = 3.6\text{s}$（相对于投放时刻）。

**求解步骤**：
1. 计算投放点 $\mathbf{F}(t_d)$ 和起爆点 $\mathbf{P}_b$
2. 在 $t \in [t_d + t_b, t_d + t_b + 20]$ 区间内以 $\Delta t = 0.01\text{s}$ 为步长
3. 对每个时刻计算线段-球相交判定
4. 统计满足条件的时长

### 3.2 问题2 —— 单机单弹优化

**优化变量**：$\mathbf{x} = (v, \theta, t_d, t_b)$
**优化目标**：$\max J = T_{\text{eff\_jam}}$
**约束条件**：
- $v \in [70, 140]$
- $\theta \in [0°, 360°)$
- $t_b \geq t_d$
- $t_d + t_b \leq T_{\text{arrive}}$（导弹到达原点之前起爆）

**求解方法**：网格搜索+局部优化。先以粗粒度网格搜索确定优秀区域，再以梯度下降或模式搜索精化。

### 3.3 问题3 —— 单机三弹优化

**优化变量**：3组投放参数 $(t_d^k, t_b^k), k=1,2,3$，以及无人机参数 $(v, \theta)$
**约束条件**：$t_d^{k+1} - t_d^k \geq 1\text{s}$（投放间隔不小于1秒）

**求解方法**：使用粒子群优化（PSO）算法，将约束通过罚函数处理。

### 3.4 问题4 —— 三机协同优化

**优化变量**：3架无人机各自的 $(v_j, \theta_j, t_d^j, t_b^j), j=1,2,3$
**优化目标**：最大化对 M1 的总有效遮蔽时长（注意多团重叠时段不重复计数）

**求解方法**：采用交替优化策略或 PSO。

### 3.5 问题5 —— 五机三目标协同优化

**优化变量**：5架无人机，每架至多3弹，分配给 M1/M2/M3 三枚导弹
**优化目标**：最大化对所有导弹的总有效遮蔽时长

**求解方法**：
- 第一阶段（目标分配）：使用 K-means 聚类或匈牙利算法分配无人机-导弹配对
- 第二阶段（参数优化）：对每枚导弹，优化分配给它的无人机/弹药的参数

### 3.6 评价指标

| 指标 | 定义 |
|------|------|
| 有效遮蔽时长 | 导弹-目标连线穿过烟幕云团的累计时间 |
| 遮蔽覆盖率 | 有效遮蔽时长 / 导弹飞行总时长 |
| 协同效率 | 多机协同时的重叠时间比例 |

## 四、数据要求

### 4.1 输出表格格式

**result1.xlsx**（问题3）：FY1投放3枚干扰弹
- 无人机运动方向、速度
- 3枚弹的投放点坐标(x,y,z)、起爆点坐标(x,y,z)、有效干扰时长

**result2.xlsx**（问题4）：FY1/FY2/FY3各投1枚
- 每架无人机的方向、速度
- 每枚弹的投放点、起爆点坐标、有效干扰时长

**result3.xlsx**（问题5）：5架无人机协同
- 每架无人机的方向、速度
- 每枚弹的投放点、起爆点坐标、有效干扰时长、干扰的导弹编号

### 4.2 数据预处理

- 所有坐标保留2位小数
- 角度精确到0.1度
- 时间精确到0.01秒

## 五、实现要求

### 5.1 编程语言

Node.js (JavaScript) —— 环境中无可用的 Python，使用 Node.js 实现所有算法。

### 5.2 主要功能模块

1. 运动学计算模块 —— 导弹/无人机/干扰弹/云团的轨迹计算
2. 几何判定模块 —— 线段-球相交判断
3. 优化求解模块 —— PSO/网格搜索
4. 结果输出模块 —— Excel 文件写入

### 5.3 输出要求

- 结果写入 Excel 文件（result1.xlsx, result2.xlsx, result3.xlsx）
- 可视化图表：导弹轨迹、无人机轨迹、烟幕云团、遮蔽时间线
- 关键中间结果输出到终端

## 六、注意事项

1. 无人机在固定高度飞行，方向变化仅发生在 $xy$ 平面
2. 烟幕云团为球形，不考虑风的影响
3. 导弹始终直线飞行，不考虑末端机动
4. 多枚弹的云团重叠时段在处理遮蔽时长时不应重复计算
5. 重力加速度取 $g = 9.8 \text{m/s}^2$
